# Support

Use GitHub Issues for reproducible bugs, rule proposals, slop-pattern submissions, eval proposals and clinical UI safety concerns. Use GitHub Discussions, when enabled, for open-ended design questions, examples and community debate.

Before posting, remove all patient data, customer-confidential material, credentials and private product details. Reproduce healthcare examples with synthetic data.

Clinical UI Skills does not provide medical advice, regulatory approval, product certification or case-specific clinical safety validation.
