# Changelog

All notable changes to Clinical UI Skills are documented here.

## [0.1.0] — 2026-08-31

First public release.

### Skills

- 12 Agent Skills covering routing, anti-slop, clinician dashboards, patient charts, patient management, forms, safety UI, data visualization, patient-facing UI, accessibility, clinical AI UI and audit.

### Evaluation

- 72 synthetic evaluation scenarios across 10 categories.
- Clinical UI Score (0–100) and separate AI Slop Score (0–10).
- ClinicalUIBench submission schema, scorer, leaderboard builder, review protocol and blinding/adjudication guidance.

### Tooling

- stdlib-only skill installer with clinician/patient/operations/AI/all presets;
- heuristic frontend linter with machine-readable rules;
- repository/eval/submission validators;
- unit tests and GitHub Actions CI.

### Launch assets

- three reproducible before/after HTML demos and screenshots;
- social preview image;
- ClinicalUIChallenge workflow;
- launch kit, issue forms, PR template, governance, security and contribution docs.
