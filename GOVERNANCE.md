# Governance

Clinical UI Skills is an open-source project created and maintained by **Juan Mora Delgado**.

## Decision principles

Changes should improve one or more of: healthcare task fit, information hierarchy, safety-oriented interaction, accessibility, data clarity, reproducibility or anti-slop discipline without masquerading taste as evidence.

## Rule changes

A rule should identify its scope and evidence level. Project heuristics may be changed or removed when reproducible examples or stronger evidence contradict them.

## Benchmark changes

Changes to score weights, caps or eval prompts must be documented in `CHANGELOG.md`. Comparative benchmark results should state the benchmark version.

## Contributions

Pull requests are welcome. Maintainer review is required before merge. The project may add additional maintainers as the contributor community grows.
