# Terminology

**AI slop:** project term for recognizable, unexamined model-generated interface defaults weakly tied to product context. Not a scientific/regulatory classification.

**Clinical UI Score:** project 0–100 heuristic quality rubric. Not a compliance/safety certification.

**AI Slop Score:** project 0–10 heuristic measure of generic AI visual patterns.

**L0 context:** persistent scope/identity information needed to understand what the user is viewing/acting on.

**L1 action-driving information:** information likely to change immediate task/action.

**L2 supporting information:** information supporting interpretation but not always first-order prominence.

**L3 detail:** metadata/history/detail available on demand.

**Work object:** repeated entity the user acts on: patient, result, task, order, message, appointment, etc.

**Semantic state:** meaningful product state such as pending, cancelled, unavailable or reviewed. Styling follows the semantic model.

**Slop tell:** a pattern warranting inspection but not automatically wrong.
