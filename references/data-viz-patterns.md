# Clinical Data Visualization Patterns

## Exact-value review
Use a table/aligned values when exact comparison dominates.

## Irregular longitudinal trend
Use a real time axis; preserve exact values/units and visibly represent gaps.

## Small multiples
Useful for repeated comparable trends without line spaghetti. Label scale differences clearly.

## Patient-facing result
Value → unit/time → product-supplied interpretation → next step → simple trend → source detail.
