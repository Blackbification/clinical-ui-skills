# Safety-Oriented UI Principles

Cross-cutting project heuristics. Not a substitute for formal safety/risk management.

For consequential actions, expose patient/object scope, action, parameters, freshness/completeness and reversibility. Model lifecycle, review, availability, priority and action states separately before styling. Color may reinforce but must not solely carry consequential meaning.

Alert salience should follow urgency, consequence, novelty and need for interruption. Confirmations should state object + action + consequence. Preserve input and enable recovery on failure. On patient/object switching, clear or re-scope stale actionable state immediately.

Never equate not loaded, not recorded, unknown, not assessed, unavailable or not applicable with a true negative.

AI-generated information should be labeled and distinguishable from source record; expose provenance when supported and useful.
