# Accessibility Baseline

Default web target: **WCAG 2.2 Level AA**. This checklist is not a conformance claim.

Use semantic landmarks/headings, real buttons and links, table semantics for tabular data, programmatic form labels, complete keyboard access, visible focus, logical focus order, adequate contrast, non-color state cues, practical touch targets, alternatives to drag-only gestures, specific field errors and usable zoom/reflow.

For clinical UI specifically, keep patient identity perceivable with assistive technology, keep units with values in reading order, preserve table header associations, give row actions useful accessible names and ensure warning meaning does not depend on icon/color.

For data visualization, provide a structured alternative where needed and never make essential values hover-only.

Explicitly check WCAG 2.2 concerns including focus not obscured, dragging alternatives, target size, redundant-entry reduction and accessible authentication.
