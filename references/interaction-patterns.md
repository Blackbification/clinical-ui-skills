# Interaction Patterns

## Worklist with inline exception signals
Stable identity/object column → comparable fields → high-value exceptions → freshness → scoped row action.

## Overview + detail
Compact overview → prioritized current data → detail disclosure → history separated from current.

## Contextual warning
Place warnings near the field/object/action they affect when interruption is not required.

## Blocking confirmation
Use only when consequence justifies interruption. Include object + action + consequence.

## Patient result explanation
Result/value → date → supplied status/interpretation → next step → more detail → source data.

## Generated summary with provenance
Label generated output, keep source reachable and do not visually merge inference into authoritative record.

## Semantic empty state
“No results match filters”, “results could not be loaded” and “no recorded allergies” are distinct states.
