# Clinical UI Score

A project heuristic for reviewing healthcare frontend outputs. It is not a clinical-safety, usability, WCAG or regulatory certification.

| Dimension | Max |
|---|---:|
| Clinical context fit | 15 |
| Information hierarchy | 15 |
| Task efficiency | 15 |
| Safety & error resistance | 20 |
| Accessibility | 15 |
| Data clarity | 10 |
| Visual intentionality | 5 |
| Anti-slop discipline | 5 |
| **Total** | **100** |

Score each dimension from observed evidence. Record BLOCKER/HIGH/MEDIUM/LOW findings separately.

Project caps: unresolved blocker → total max 49; two or more unresolved HIGH safety findings → safety dimension max 8/20; inaccessible primary task → accessibility max 7/15.

## AI Slop Score

Separate 0–10 score where lower is better. It captures the degree to which generic AI-generated frontend patterns dominate the visible design. Do not use it as a proxy for clinical UI quality.
