# Clinical UI Principles

1. Start with user × task × consequence × environment, not a visual genre.
2. Keep patient/action scope persistent enough for the workflow.
3. Model semantic state before assigning colors or badges.
4. `unknown ≠ no`, `unavailable ≠ empty`, `pending ≠ negative`, `historical ≠ current`.
5. Put action-driving information above decorative analytics.
6. Choose representation by task: aligned rows/table for comparison, timeline for chronology, cards for coherent objects, charts only when shape answers a question.
7. Allow task-appropriate professional density.
8. Never use color as the sole carrier of consequential meaning.
9. Keep units, timestamps and provenance available when they affect interpretation.
10. Treat accessibility as task performance, not polish.
11. Distinguish AI-generated content from source record.
12. Render, inspect, audit and revise.
13. Anti-slop is subordinate to safety, accessibility and task effectiveness.
14. Do not invent clinical thresholds, advice or institutional policy to complete a UI.
