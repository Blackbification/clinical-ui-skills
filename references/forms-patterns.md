# Clinical Form Patterns

## Measurement field
Visible label + input + persistent unit + format/help + associated error.

## Three-state question
When semantics require it, represent `Yes / No / Unknown` explicitly rather than turning blank into No.

## Conditional section
State trigger clearly, reveal fields predictably, and define what happens to entered child data if the parent answer changes.

## Consequential confirmation
Use object + action + consequence. Avoid generic “Are you sure?”.

## Draft/save
Expose draft/saving/saved/failed. Preserve data on recoverable failure.
