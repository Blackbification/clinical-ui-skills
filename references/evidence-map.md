# Evidence Map

Last web-verified: **2026-08-31**.

This map separates external guidance/research from project heuristics. Inclusion does not mean every Clinical UI Skills rule is mandated by the source.

| Project concept | Source | Source type |
|---|---|---|
| user × task × use-environment framing | FDA Human Factors Considerations | US regulatory/public guidance |
| minimize use-related risk | FDA Human Factors and Medical Devices | US regulatory/public guidance |
| EHR effectiveness, efficiency and use-safety | NIST Technical Basis for UI Design of Health IT | government usability research |
| patient-identification safety | ONC SAFER Patient Identification | health-IT safety guidance |
| order/CDS alert/warning practices | ONC SAFER CPOE with Decision Support | health-IT safety guidance |
| results follow-up safety | ONC SAFER Test Results Reporting and Follow-Up | health-IT safety guidance |
| web accessibility baseline | WCAG 2.2 | W3C Recommendation |
| concise/specific warning content | NHS warning callout | public healthcare design system |
| chart and patient-management problem classes | OpenMRS | open healthcare software |
| anti-slop direction / render-audit precedent | anti-ai-slop-ui, unslop-ui, repaint | open Agent Skills/projects |
