# Clinical AI UI Patterns

## Generated summary with source anchors
Label generated content, expose source anchors when supported, and keep authoritative source data reachable.

## Extraction review
Show source context + extracted field + review state + accept/edit/reject. Avoid chat for field-by-field verification.

## Proposed agent action
State target patient/object + proposed action + parameters + reversibility/confirmation + execution result.

## Failure
State what failed, whether any state changed, and what the user can do next.
