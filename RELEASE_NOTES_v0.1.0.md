# Clinical UI Skills v0.1.0

**Stop coding agents from turning healthcare software into generic AI SaaS.**

The first public release ships a complete open Agent Skills suite for healthcare frontend generation and audit:

- 12 interoperable skills;
- 72 synthetic evals;
- Clinical UI Score + AI Slop Score;
- ClinicalUIBench tooling;
- install presets for clinician, patient, operations and AI surfaces;
- heuristic source linter;
- three reproducible before/after demos;
- CI, tests, issue forms, challenge workflow and public methodology.

The project is deliberately not a healthcare design system and not a compliance certificate. It teaches coding agents to make frontend decisions from user, task, risk, information hierarchy, state, accessibility and use environment before reaching for generic SaaS patterns.

**One rule:** `NO UNEXAMINED DEFAULTS.`
