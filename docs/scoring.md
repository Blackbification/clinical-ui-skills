# Scoring Guide

Use `references/clinical-ui-score.md` as canonical rubric.

Recommended process: blocker screen → eight independent dimension scores → caps → total → separate AI Slop Score → top three changes → re-score after revision.

Do not infer interaction quality from a screenshot when the app is available; infer clinical correctness from polish; reward unusual design; automatically punish density; or claim WCAG conformance without proper testing.

For ClinicalUIBench, remove model/condition identifiers, randomize outputs, use the same rubric, collect per-dimension scores and blocker/high findings, calculate agreement and adjudicate large disagreements. Report distributions/medians, not one aggregate number alone.
