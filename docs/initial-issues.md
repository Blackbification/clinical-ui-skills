# Suggested Starter Issues

Seed the public repository with real work, not fake activity.

1. **Build a browser screenshot audit harness** — capture desktop/tablet/mobile states and produce a machine-readable evidence bundle for `clinical-ui-audit`.
2. **Add an optional axe accessibility adapter** — integrate automated accessibility findings without presenting them as WCAG conformance.
3. **Create a React + Tailwind integration example** — demonstrate skill-driven generation without coupling the project to one design system.
4. **Add a clinical messaging / handoff eval pack** — synthetic inbox, escalation, referral and care-transition scenarios.
5. **Run the first blinded dashboard comparison** — `dashboard-01`, vanilla vs Clinical UI Skills, same model/tooling.
6. **Run the first patient-facing comparison** — `patient-facing-02`, with blinded scoring and full artifacts.
7. **Measure reviewer agreement** — pilot two or more reviewers on a 10-output subset and report disagreements.
8. **Add machine-readable audit JSON schema** — structured blockers/findings/scores/verification plan.
9. **Expand linter tests for Vue/Svelte/React** — keep rules conservative and document false-positive classes.
10. **Contribute a Wall of Clinical Slop pattern** — recreate one recurring failure with synthetic data and propose an eval assertion.
11. **Add a responsive dense-table pattern reference** — preserve comparison on tablet/mobile without cardification.
12. **Create a benchmark run card template** — model/client/settings/tool access/iteration budget/viewport and deviations.
