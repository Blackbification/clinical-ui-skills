# Suggested GitHub Labels

Create these after the repository is live. GitHub issue forms reference some of them, but labels can be added incrementally.

| Label | Purpose |
|---|---|
| `bug` | reproducible tooling/repository defect |
| `safety` | UI safety/state concern; not a medical incident channel |
| `accessibility` | accessibility issue or improvement |
| `slop-pattern` | candidate Clinical Slop Catalog pattern |
| `eval` | new/changed eval scenario |
| `benchmark` | ClinicalUIBench submission/methodology |
| `challenge` | #ClinicalUIChallenge submission |
| `skill` | skill proposal/change |
| `evidence` | source/evidence-map contribution |
| `good first issue` | scoped contributor task |
| `help wanted` | maintainer requests community input |
| `discussion-needed` | rule/benchmark change needing broader review |
